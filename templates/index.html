02 / Process

How it works

From simple measurements to a machine learning prediction in three straightforward steps.

01 — MEASURE

Capture the details

Enter the sepal and petal dimensions of the flower in centimeters.

02 — ANALYZE

Process the pattern

The trained Logistic Regression model analyzes the four measurements.

03 — IDENTIFY

Reveal the species

IrisVision displays the predicted species together with its corresponding flower image.

03 / About

Powered by Machine Learning.

IrisVision is a machine learning based flower classification application built using the classic Iris dataset. It uses a trained Logistic Regression model to classify flowers from four physical measurements.
